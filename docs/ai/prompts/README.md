# Промпты

Здесь лежат промпты, которые стоит показать жюри или переиспользовать. Один промпт, один файл.

Имя файла: `<раздел>-<что-делали>.md`, например `schedule-week-api.md` или `design-moodboard.md`.

Внутри:

```
# Что делали

- Агент и модель:
- Дата:
- Этап: идея, дизайн, каркас, раздел кабинета, тесты, деплой, описание процесса
- PR:

## Промпт

(текст целиком, как отправили)

## Что получилось

Коротко: что сделал агент, что пришлось поправить, был ли второй заход и чем он отличался.
```
