# Дизайн

Здесь лежат мудборд, выбранный визуальный стиль, дизайн-токены, схема экранов и макеты. Тяжёлые скриншоты для описания процесса держим в общей папке на диске, а сюда кладём только то, что нужно для работы.

## Токены

Заполним, когда выберем стиль. В коде они живут в CSS-переменных в `frontend/src/shared/ui`, и значения здесь и там должны совпадать.

| Токен | Значение | Где используется |
|---|---|---|
| | | |

Шрифт и иконки берём только с открытой лицензией, например шрифты под OFL и иконки Lucide (ISC). Лицензию записываем рядом с названием.
