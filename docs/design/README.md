# Визуальный стиль цифрового деканата

Документ фиксирует визуальный язык интерфейса: референсы, направление главного экрана, цвета, типографику, отступы, иконки и статусы.

Интерфейс должен быть спокойным, понятным и доступным. Цвет не является единственным способом передать статус, ошибку или предупреждение.

## Направления главного экрана

### Вариант 1: «Спокойный кабинет»

Главный экран выглядит как спокойная лента дел студента. Сверху стоит следующая пара, ниже - сроки, важные уведомления, допуск к сессии и активные заявки.

```text
┌──────────────────────────────────────────┐
│ Сегодня, 7 ноября          🔔 3   👤      │
├──────────────────────────────────────────┤
│ Следующая пара                           │
│ ┌──────────────────────────────────────┐ │
│ │ 12:20-13:50                          │ │
│ │ Математический анализ                │ │
│ │ ауд. 305 · Иванов И. И.              │ │
│ │ Перенос: было 10:40, ауд. 214        │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ Ближайший срок                           │
│ ┌──────────────────────────────────────┐ │
│ │ Подать на пересдачу по физике        │ │
│ │ до 18 ноября · осталось 11 дней      │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ Важное                                   │
│ ┌──────────────────────────────────────┐ │
│ │ Допуск к сессии                      │ │
│ │ Не сдана лабораторная №3 по физике.  │ │
│ │ [Подать на пересдачу]                │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ Активные заявки                          │
│ ┌──────────────────────────────────────┐ │
│ │ Справка в военкомат · В работе       │ │
│ │ Готовность примерно 12 ноября        │ │
│ └──────────────────────────────────────┘ │
├──────────────────────────────────────────┤
│ Сегодня  Расписание  Учёба  Заявки  Профиль │
└──────────────────────────────────────────┘
```

Плюсы: спокойно, понятно, легко масштабировать на новые разделы.  
Минусы: главный экран может стать длинным, если добавить много типов карточек.

### Вариант 2: «План на день»

Главный экран собран как расписание дня с состоянием дел. Пары идут в хронологическом порядке, а сроки, заявки и объявления встроены между ними.

### Вариант 3: «Карточки действий»

Главный экран собран вокруг действий: следующая пара, что сдать, какие заявки активны и что изменилось. Каждый блок заканчивается понятной кнопкой.

```text
┌──────────────────────────────────────────┐
│ Сегодня, 7 ноября          🔔 3   👤      │
├──────────────────────────────────────────┤
│ Куда идти                                │
│ ┌──────────────────────────────────────┐ │
│ │ 12:20-13:50 · Матанализ              │ │
│ │ ауд. 305 · Иванов И. И.              │ │
│ │ Перенос: было 10:40, ауд. 214        │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ Что сделать                              │
│ ┌──────────────────────────────────────┐ │
│ │ Подать на пересдачу по физике        │ │
│ │ до 18 ноября                         │ │
│ │ [Подать]                             │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ Что изменилось                           │
│ ┌──────────────────────────────────────┐ │
│ │ Консультация по физике перенесена    │ │
│ │ на 16:30, ауд. 305                   │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ Мои заявки                               │
│ ┌──────────────────────────────────────┐ │
│ │ Справка в военкомат · В работе       │ │
│ │ Готовность примерно 12 ноября        │ │
│ │ [Открыть]                            │ │
│ └──────────────────────────────────────┘ │
├──────────────────────────────────────────┤
│ Сегодня  Расписание  Учёба  Заявки  Профиль │
└──────────────────────────────────────────┘
```

Плюсы: студент сразу видит, что делать, а не только информацию.  
Минусы: нужно ограничивать число действий, чтобы экран не превратился в список задач.

## Выбранное направление

Выбираем вариант 1 - «Спокойный кабинет».

Он лучше всего отвечает главной задаче: студент на одном экране видит, куда идти, что изменилось, какой срок близко и что происходит с заявками. При этом интерфейс остаётся спокойным и не превращается в список напоминаний.

Порядок блоков главного экрана должен совпадать с `docs/design/screens.md`:

1. Следующая пара.
2. Ближайший срок.
3. Важные уведомления и объявления.
4. Активные заявки.

На «Сегодня» показываются только важные объявления. Обычные объявления доступны в разделе объявлений и не выводятся отдельным блоком на главном экране.

## Палитра

| Токен | Значение | Где используется |
|---|---|---|
| `color-primary` | `#1F5EFF` | Основные кнопки, активный пункт меню, ссылки |
| `color-primary-hover` | `#1747CC` | Нажатие основной кнопки |
| `color-accent` | `#FFB020` | Только фон важных сроков и предупреждений |
| `color-accent-text` | `#5C3A00` | Текст на жёлтом акцентном фоне |
| `color-success` | `#0E8A4C` | Фон успешных статусов, крупные графические элементы |
| `color-success-text` | `#0B6B3A` | Обычный зелёный текст и текст успешных бейджей |
| `color-warning` | `#B45309` | Перенос пары, приближающийся срок |
| `color-danger` | `#C0392B` | Отмена пары, долг, отклонённая заявка |
| `color-bg` | `#F6F7F9` | Фон страницы |
| `color-surface` | `#FFFFFF` | Карточки, поля ввода, меню |
| `color-border` | `#DDE1E6` | Декоративные границы карточек и разделители |
| `color-border-input` | `#6B7280` | Видимая граница полей ввода |
| `color-text` | `#111827` | Основной текст |
| `color-text-secondary` | `#5B6472` | Второстепенный текст, подписи |
| `color-text-on-primary` | `#FFFFFF` | Текст на синей кнопке |

### Правила контраста

- `#111827` на `#FFFFFF` - основной текст.
- `#5B6472` на `#FFFFFF` - второстепенный текст.
- `#FFFFFF` на `#1F5EFF` - текст на основной кнопке.
- `#0B6B3A` на `#FFFFFF` - обычный зелёный текст и текст статусов `Ready`, `Issued`, `Passed`.
- `#0E8A4C` на `#FFFFFF` даёт контраст 4.41:1. Для обычного текста он не проходит AA; использовать только для крупного текста или не текстовых элементов.
- `#FFB020` на `#FFFFFF` даёт контраст 1.83:1. Его нельзя использовать как цвет текста; допустимо только как фон с тёмным текстом `#5C3A00`.
- `#DDE1E6` на `#FFFFFF` даёт контраст 1.31:1. Подходит для декоративной границы карточки, но не для границы поля ввода.
- Граница поля ввода должна иметь контраст не ниже 3:1; используется `#6B7280`.

## Типографика

Используем **Onest**. Шрифт распространяется по SIL Open Font License 1.1, поддерживает кириллицу и хорошо читается в интерфейсе. [github](https://github.com/google/fonts/blob/main/ofl/onest/OFL.txt)

Шрифт подключается локально через пакет `@fontsource/onest`. Нельзя загружать Onest с Google Fonts или другого внешнего CDN: сайт не должен зависеть от внешних сервисов, которые могут быть недоступны из России.

| Токен | Размер и высота строки | Начертание | Где используется |
|---|---:|---|---|
| `font-display` | 28 px / 34 px | 700 | Заголовок экрана |
| `font-title` | 20 px / 26 px | 600 | Заголовок карточки |
| `font-body` | 16 px / 24 px | 400 | Основной текст |
| `font-body-strong` | 16 px / 24 px | 600 | Важный текст в карточке |
| `font-caption` | 14 px / 20 px | 400 | Подписи, статусы, вспомогательный текст |
| `font-small` | 12 px / 16 px | 500 | Метки, счётчики, служебный текст |

## Тени и границы

| Токен | Значение | Где используется |
|---|---|---|
| `shadow-card` | `0 1px 2px rgba(17, 24, 39, 0.06)` | Обычная карточка |
| `shadow-raised` | `0 4px 12px rgba(17, 24, 39, 0.08)` | Модальное окно, всплывающее меню |
| `border-card` | `1px solid #DDE1E6` | Карточка на светлом фоне |
| `border-input` | `1px solid #6B7280` | Поле ввода |
| `border-focus` | `2px solid #1F5EFF` | Фокус в поле ввода и на кнопке |

Тени используются редко: интерфейс должен оставаться спокойным и хорошо читаться на слабом экране телефона.

## Иконки

Используем **Lucide**. Лицензия ISC разрешает использование, изменение и распространение иконок. [github](https://github.com/lucide-icons/lucide/blob/main/LICENSE)

В коде и документации используем актуальные названия иконок Lucide. Старые имена могут работать как алиасы, но новые названия предпочтительны.

| Экран или действие | Иконка Lucide |
|---|---|
| Сегодня | `house` |
| Расписание | `calendar-days` |
| Учёба | `graduation-cap` |
| Заявки | `file-text` |
| Уведомления | `bell` |
| Профиль | `user` |
| Перенос пары | `calendar-sync` |
| Отмена пары | `circle-x` |

| Ошибка | `octagon-alert` |
| Выход | `log-out` |

## Макет выбранного направления

![Главный экран, вариант "Спокойный кабинет"](home-mockup.png)

Макет собран по токенам из этого файла: шрифт Onest подключён локально, иконки Lucide, ширина экрана 360 px. ASCII-схемы выше показывают только структуру, а здесь видно, как работают цвета, шрифт и статусы:

- перенос пары выделен оранжевым, прежние время и аудитория зачёркнуты;
- ближайший срок стоит на жёлтом фоне с тёмным текстом `#5C3A00`;
- недопуск отмечен красной полосой, иконкой и подписью, а не только цветом;
- статус заявки показан бейджем с текстом.

## Что фиксируем для прототипа

- Шрифт: Onest, подключённый локально через `@fontsource/onest`.
- Иконки: Lucide, с актуальными названиями.
- Основной цвет: `#1F5EFF`.
- Фон: `#F6F7F9`.
- Карточки: белые, радиус 12 px, тонкая декоративная граница.
- Главная кнопка: синяя, радиус 12 px, высота 48 px.
- Карточка следующей пары: вверху главного экрана.
- Перенос: новое время и аудитория крупно, прежние значения зачёркнуты.
- Важное объявление: жёлтый фон с тёмным текстом, карточка на «Сегодня».
- Обычные объявления: не показываются на «Сегодня».
- Статус заявки: цветной бейдж с русским названием статуса и текстовой меткой.
